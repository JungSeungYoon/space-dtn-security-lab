# Glossary

Only minimal, source-backed definitions belong here. Extend during study.

- **Bundle:** The BP protocol data unit, composed of one primary block and one or
  more canonical blocks, including exactly one payload block (RFC 9171).
- **BPv7:** Bundle Protocol Version 7, specified by RFC 9171.
- **BPSec:** Bundle Protocol Security, the BPv7 security-block framework in RFC 9172.
- **BIB:** Block Integrity Block, a BPSec block providing integrity for selected
  plaintext security targets (RFC 9172).
- **BCB:** Block Confidentiality Block, a BPSec block encrypting selected security
  targets and providing integrity protection for its ciphertext (RFC 9172).
- **CBOR:** Concise Binary Object Representation, the binary data format specified
  by RFC 8949 and used by BPv7 bundle encoding.
- **Contact plan:** A schedule/model of anticipated communication opportunities;
  exact ION representation and semantics remain to be studied.
- **DTN:** Delay/Disruption Tolerant Networking; networking designed to operate
  across delays and disruptions, commonly using store-and-forward behavior.
- **ION:** Interplanetary Overlay Network, a JPL-developed DTN implementation.
