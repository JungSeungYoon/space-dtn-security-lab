# Responsible Security Research

- Perform attack experiments only in local or explicitly authorized environments.
- Never target operational spacecraft, ground stations, or third-party networks.
- Do not store credentials, tokens, or private keys in the repository.
- Reproduce suspected vulnerabilities, establish root cause, and assess impact
  before making a claim.
- Do not publish a new vulnerability prematurely. Coordinate with the appropriate
  upstream maintainer when responsible disclosure is warranted.
- Keep PoCs and attack code scoped to reproducible research, minimize dangerous
  defaults, and document safe execution boundaries.
- Stop an experiment that escapes its intended boundary or risks unrelated systems.
